# Active agent claims

Live lock file so multiple agents (Claude sessions, subagents, or anything
else touching this repo) working on `docs/ROADMAP.md` batches at the same time
don't step on each other. This file is the claim board, not the plan —
`docs/ROADMAP.md` has the batch scope and checklist.

## Protocol

**Before starting a batch:**

1. Read this file.
2. If your batch number already has a row with status `claimed`, stop and pick
   a different batch, or coordinate with whoever holds it — do not start
   anyway.
3. Add a row for your batch: your agent name, the batch number, `claimed`,
   the current UTC time, and which shared files you expect to touch
   (`services/cloudflare.ts`, specific `locales/*.json` namespaces,
   `app/_layout.tsx`, or "none" if your batch is fully self-contained).

**While working:** if you are not in an isolated git worktree, re-check this
file before writing to any of the three shared files
(`services/cloudflare.ts`, `locales/*.json`, `app/_layout.tsx`) — someone else
may have claimed an overlapping batch after you started.

**When done (or abandoning):** update your row's status to `done` or
`abandoned` and add the finish time. Do not delete the row — it is the log of
who touched what.

**Naming yourself:** pick something identifiable and short — e.g. `claude-1`,
`claude-worker-batch`, `sonnet-tier2`. If you don't know your own name, ask the
user what to call yourself for this run rather than leaving the column blank.
