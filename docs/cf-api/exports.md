# exports

6 endpoints.

## POST /accounts/{account_id}/data-security/posture/content/export

Create a content export

operationId: `CreateContentExport`

**Request** (application/json)

- `dlp_profile_id`: string[] — Filter by DLP profile IDs.
  [array]
- `dlp_profile_information`: object[] **required** — DLP profile metadata for the export.
  [array of]
  - `entries`: object[] **required** — Entries contained within this DLP profile.
    [array of]
    - `id`: string **required** — Unique identifier for the DLP profile entry.
    - `name`: string **required** — Name of the DLP profile entry.
    - `profile_id`: string **required** — ID of the parent DLP profile.
  - `id`: string **required** — Unique identifier for the DLP profile.
  - `name`: string **required** — Name of the DLP profile.
- `integration_id`: string[] — Filter by integration IDs.
  [array]
- `max_affliction_date`: string — Filter to view content flagged on or before this date.
- `min_affliction_date`: string — Filter to view content flagged on or after this date.
- `orders`: object[] — Ordering specifications for the export.
  [array of]
  - `direction`: string **required** enum: `asc`, `desc` — Sort direction.
  - `name`: string **required** — Field name to order by.
  - `name`: string **required** enum: `asset_name`, `dlp_profile_count`, `integration_name`, `latest_affliction_date` — Content-specific field names for ordering.
- `search`: string — Search term to filter content.
- `vendors`: string[] — Filter by vendor types.
  [array]

**Response** 200 → `result`

- `download_url`: string — The URL by which the successfully created export can be downloaded by the end users.
- `errors`: string — Contains information on errors which may have occurred during export creation.
- `file_name`: string — The base name of the file that is/was generated by the export job.
- `file_path`: string — The full path of the file that is stored within external storage (currently R2).
- `id`: string **required** — Unique identifier for the export job.
- `status`: string **required** enum: `Pending`, `Success`, `Failure`, `Rescheduled`, `In-Progress` — Status of an export job.
- `type`: string **required** enum: `finding`, `findingInstance`, `content`, `remediationJob` — Type of export job.
- `user_id`: string **required** — ID of the export-requesting user.
